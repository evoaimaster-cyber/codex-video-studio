# Codex Video Studio

Codex Video Studioは、台本を起点に、画像・動画・音声・字幕を組み合わせて動画を編集するためのアプリです。Codexとアイデアを相談するところから、素材を準備し、手元の編集画面で映像を確かめてMP4に書き出すところまで、制作の流れをつなぎます。

短い紹介動画や説明動画など、「何を伝えるか」は決まっていても、どんな場面に分け、どんな素材を用意すればよいか迷うときに使うイメージです。まず言葉で内容を整理し、その内容に合った映像を集めてから編集を進めます。

## 動画づくりの流れ

1. **Codexと内容を相談する**  
   伝えたいことや見る人を整理し、企画、プロット、シナリオ、台本を考えます。場面ごとの内容や字幕の言葉も、相談しながら整えます。

2. **画像や動画の開始画像を準備する**  
   台本に合わせて、場面に使う画像や、動画生成の出発点になる開始画像を用意します。手元にある素材も制作に活かせます。

3. **外部AIのWeb画面で動画を依頼する**  
   場面の動きや見せ方を動画プロンプトにまとめ、選んだ外部AIサービスのWeb画面に渡して生成を依頼します。生成された素材を取得し、編集に使うものを選びます。

4. **素材をアプリで編集する**  
   取得した素材をアプリに取り込み、MCPを介してCodexでの相談とアプリの編集作業をつなぐ構成です。台本で内容を確認し、タイムラインで素材の順番や秒数を調整します。字幕や音声も合わせて整えます。

5. **再生して確認し、MP4に書き出す**  
   プレビューで場面のつながり、字幕のタイミング、音声を確認します。必要な箇所を修正し、仕上げた動画をMP4として書き出します。

台本とタイムラインは別の画面で扱えるため、文章を考える作業と映像の時間を調整する作業を切り替えて進められます。素材の取り込み、場面の秒数設定、字幕・音声の調整、プレビュー、書き出しを、動画づくりの流れに沿って使うアプリです。

MCPはCodexとアプリをつなぐための接続です。CodexとのMCP連携は、利用環境での接続確認が必要です。動画生成の依頼は、利用する外部AIサービスのWeb画面で行う想定です。
